Description complète
MileTax aide les travailleurs autonomes à organiser leurs dossiers professionnels : véhicules, kilométrage, reçus, dépenses et revenus. Vous préparez un paquet clair à remettre à votre comptable.

Les totaux à l’écran sont la somme de ce que vous avez saisi, pas un montant d’impôt. Conservez vos originaux.

COMPTE PLAY + BUILD
================================================================
1. play.google.com/console — créer l’app « MileTax », package com.miletax.app (ne plus le changer)
2. Politique + conditions + Data safety + fiche FR (et EN)
3. miletaxe.com doit servir en HTTPS public :
   https://miletaxe.com/legal/privacy
   https://miletaxe.com/legal/delete-account
   Play → Politique de suppression de compte : coller https://miletaxe.com/legal/delete-account
   Dans l’app : oui. Par le web : demande à support@miletaxe.com (30 jours). Données : tout le compte et les dossiers.
4. Compte Expo : npx eas-cli login   puis   npx eas-cli init
5. Secrets de build (URL + clé anon, déjà dans .env local) :
   npx eas-cli secret:create --scope project --name EXPO_PUBLIC_SUPABASE_URL --value …
   npx eas-cli secret:create --scope project --name EXPO_PUBLIC_SUPABASE_ANON_KEY --value …
6. AAB : npx eas-cli build --profile production --platform android
7. Play → Tests → Test interne (pas Production) → créer une piste, ajouter votre Gmail testeur, uploader l’AAB
8. Quand le test interne s’ouvre et que la politique est en ligne : demander l’examen de production

Ne pas envoyer l’admin web ni /employes comme « l’app » : seul le binaire Android compte pour la revue.
